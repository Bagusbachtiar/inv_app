# Project Plan: Shop Inventory Management System

## 🎯 Goal
To build a practical, full-stack CRUD application (Shop Inventory Management) using modern JavaScript technologies.

## 🛠️ Stack & Architecture
- **Frontend:** React
- **Backend:** Node.js + Express (REST API)
- **Database:** PostgreSQL
- **Communication:** HTTP requests
- **Authentication:** JWT
- **Testing:** Appropriate JS testing tools.

## 🗺️ Milestones (Roadmap)
1.  **Foundation Setup:** Scaffolding, basic server, and initial project structure. (CURRENTLY IN PROGRESS)
2.  **Core CRUD:** Implement API endpoints for Inventory Item creation, reading, updating, and deleting.
3.  **Database Integration:** Connect Express to PostgreSQL.
4.  **Authentication:** Implement JWT login and protected routes.
5.  **Frontend Integration:** Build React components to consume the REST API.
6.  **Refinement:** Add validation, filtering, pagination, and robust testing.

## 📜 Guiding Principles (Derived from TEACHING.md)
- **Learning Focus:** Implementation-driven learning. I must guide the user to write the code themselves.
- **Process:** Small, manageable tasks $\rightarrow$ Explanation $\rightarrow$ Code Snippet $\rightarrow$ User Implements $\rightarrow$ Testing $\rightarrow$ Concept Explanation $\rightarrow$ Next Task.
- **Documentation:** Must maintain `PROGRESS.md` (current status) and `README.md` (setup).
